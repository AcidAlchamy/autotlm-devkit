How this kit works

NODE 01 — SOURCE
Your device (or the simulator)
Telemetry frames arrive over plain HTTP at POST /api/ingest — one frame or a batched catch-up array, bearer-token authenticated.
NODE 02 — THIS KIT
DevKit
Stores frames in a per-device ring buffer and serves them back: /api/devices, /latest, /history, /dtc, and a live SSE channel — the same shapes the production cloud speaks.
NODE 03 — YOUR CODE
Whatever you're building
This console is just a client of the query API. Open the source, rip it apart, build your own — when you outgrow the laptop, the cloud speaks the same contract.
